# Archived Supabase Auth implementation

These `.txt` files are preserved source snapshots from before Clerk took over authentication. They are not imported or compiled by the application.

Clerk now owns sign-in, sign-up, recovery, sessions, invitations, and account administration. Supabase remains the database and storage provider. The legacy source is retained as reference material only; do not restore it without first reviewing the Clerk and Postgres third-party-auth design in `docs/authentication-and-permissions.md`.
